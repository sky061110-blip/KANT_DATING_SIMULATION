# Antigravity 개발 프롬프트 — KANT AFTER CLASS Expanded

이 프로젝트는 대학생을 위한 칸트 철학 입문 미연시 게임이다.

현재 구현된 핵심 기능:
- 7개 챕터
- 7개 칸트 철학 개념
- 선택지 기반 호감도 / 이해도 / 관계 깊이
- 칸트 CSS 캐릭터와 표정 5종
- 대학생 NPC 유나
- 배경 7종
- 특별 이벤트
- 미니 퀴즈
- 멀티 엔딩
- localStorage 저장
- 반응형 UI

개발 원칙:
1. 철학 학습이 미연시 장식으로 밀리지 않게 한다.
2. 설명은 짧고 이해하기 쉽게 하되, 칸트 개념을 지나치게 단순화해 왜곡하지 않는다.
3. 실제 칸트가 하지 않은 창작 대사를 실제 인용문처럼 표현하지 않는다.
4. 대학생이 실제로 할 법한 고민과 상황을 사용한다.
5. 모바일에서 선택지를 누르기 편하게 유지한다.
6. 기존 localStorage 저장 데이터와 최대한 호환한다.
7. 진짜 미연시처럼 표정/장면/관계 이벤트를 강화하되 학습 흐름은 다음 구조를 유지한다:
   상황 → 선택 → 캐릭터 반응 → 개념 피드백 → 짧은 퀴즈 → 개념 노트

다음 개선을 우선 적용해줘:
- CSS 캐릭터를 실제 일러스트 파일 기반 캐릭터 시스템으로 교체할 수 있도록 구조화
- assets/characters/kant/ 아래에 neutral, smile, surprised, thinking, annoyed 이미지가 들어오면 자동으로 사용할 수 있게 설계
- assets/characters/yuna/ 도 같은 방식
- 배경 이미지도 assets/backgrounds/에서 교체 가능하도록 설계
- 장면 전환 페이드 애니메이션
- 대사 로그 보기 버튼
- BGM on/off UI (실제 음원 파일이 없으면 버튼만 비활성 상태로)
- 설정 메뉴
- 엔딩 갤러리
- 복습 모드
