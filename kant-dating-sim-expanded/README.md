# KANT AFTER CLASS — Expanded Edition

대학생이 칸트 철학을 부담 없이 접하도록 만든 교육용 미연시(비주얼 노벨) 웹 게임입니다.

## 확장판 추가 기능

- 7일 / 7챕터 스토리
- 칸트 표정 변화
  - neutral
  - smile
  - thinking
  - surprised
  - annoyed
- 대학생 NPC `유나`
- 장면별 배경 변화
  - 카페
  - 강변
  - 강의실
  - 도서관
  - 비 오는 캠퍼스
  - 저녁 성벽
  - 밤
- 세 번째 지표 `관계 깊이`
- 특별 선택지와 관계 이벤트
- 이벤트 콜렉션
- 개념 퀴즈
- 개념 노트
- localStorage 저장 / 이어하기
- BAD / NORMAL / TRUE ENDING
- 모바일 반응형

## 철학 개념

1. 코페르니쿠스적 전회
2. 현상과 물자체
3. 선험적 인식
4. 정언명령
5. 인간성 정식
6. 자율
7. 실천이성과 희망

## 실행

### 가장 간단한 방법
`index.html`을 브라우저에서 엽니다.

### 로컬 서버
```bash
python -m http.server 8000
```

그 후:
`http://localhost:8000`

## Antigravity에서 사용

1. 이 ZIP을 압축 해제합니다.
2. Antigravity 실행
3. Projects → New Project
4. Add Folder
5. `kant-dating-sim-expanded` 폴더 선택
6. Create
7. Agent에게 `ANTIGRAVITY_PROMPT.md` 내용을 기반으로 수정 요청

## 추천 후속 개선

- 실제 캐릭터 일러스트 PNG/WebP로 교체
- 표정 스프라이트
- 장면 전환 페이드
- 선택지 로그
- BGM 및 효과음
- 설정 메뉴
- 세이브 슬롯 3개
- 챕터 선택 기능
- 중간고사 모드
- 교수님에게 제출하기 위한 학습 목표/학습성과 화면

## 주의

게임 속 칸트의 대사는 교육 목적의 창작이며 실제 발언을 인용한 것이 아닙니다.
